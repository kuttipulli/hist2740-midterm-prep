# HIST 2740 Midterm Prep (unofficial)

A free study tool for the HIST 2740 (Immigration in U.S. History) midterm. It covers all 45 identifications, each with key points: definition, context, reading and significance. It also has quick checks, essay outlines, a timed mock, flashcards and an error log.

Unofficial and not affiliated with the course. The key points paraphrase course readings and lectures, so check anything you rely on against the readings, and write your answers in your own words. Progress is saved only in your browser.
